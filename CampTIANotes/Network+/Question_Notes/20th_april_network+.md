## You are scanning a target as part of a penetration test. You discovered that the network uses Snort configured as a network-based IDS. Which of the following occurs when an alert rule has been matched in Snort during your scan?
### Snortはシスコが提供するネットワーク監視システム。IDS（Intrusion Detection System）は不正侵入検知システムでネットワークとかの不正侵入をみる。IPS（Intrusion Prevention System）は不正侵入防止システムでファイアーウォールなどで防止する方である。
## 次のケーブルタイプのうち、SATA 3.0ケーブルや、同じラックマウント型エンクロージャ内の2台のスイッチ間のアップリンクなど、非常に短距離の高速アプリケーションで使用されるものはどれですか？
### この問題は短距離を強調している。Twinaxial（ツインアキシャルケーブル）は1つのシールド（遮蔽）層の中に、2本の絶縁された中心導体を持つ「同軸ケーブル」の一種です。主にデータセンターやサーバー、スイッチ間などの短距離・高速通信（数Gbpsクラス）で、外部ノイズを抑えつつ高速かつ高精度な信号伝送を実現するために使われます。Coaxialは同軸ケーブル。SATA3.0はマザーボードやSSD/HDDをつなぐときに使う。

## ユーザーが社内ネットワークに接続しているにもかかわらず、インターネット上のウェブページにアクセスできません。適切なネットワーク/SSIDに接続されていることは確認済みです。以下のうち、この問題の最も可能性の高い原因はどれでしょうか？

## パケット交換方式の可変遅延データネットワーク上で、異なるコンピュータシステム間のクロック同期に使用されるプロトコルはどれですか？
### TFTP（Trivial File Transfer Protocol）は、ポート６５番で動きUDP上で動作する非常に簡易的なファイル転送プロトコルです。NTP（Network Time Protocol）は、ポート123番ネットワークに接続されたコンピュータや機器の時計を、正確な標準時（協定世界時：UTC）に同期するための通信プロトコルです。大体のプロトコルはアプリケーション層だってTCP/UDPはプロトコルじゃん。
## 新しいオフィスフロアのセットアップ中に、ネットワーク管理者のドロシーは、VoIP電話とワークステーションを接続するためにスイッチのポートを設定します。彼女は、音声トラフィックがデータトラフィックよりも優先されるようにしたいと考えています。ドロシーがこれを実現するのに最適な設定は次のうちどれでしょうか？
### VoIP電話が接続されているスイッチポートで、音声VLANを設定してください。音声はvoice VLAN、PCのデータはdata VLANのように分ける。トランクリンク（Trunk Link）とは、ネットワークスイッチ同士を接続し、1本の物理的な通信線（リンク）で、複数のVLAN（仮想ネットワーク）のトラフィックを伝送する方式。ネイティブVLANとは、IEEE 802.1Q規格のトランクポートにおいて、VLANタグを付けずに送受信される唯一のVLANのことです。
## エッジスイッチのどのスイッチポートにどのケーブルが接続されているかを示すラベルを含むネットワークドキュメントの種類は次のうちどれですか？
### 配線図は、どのケーブルがどのポートに接続されているかを明確に示すために使用されます。ワイヤレスサイトサーベイは、必要なワイヤレスカバレッジ、データレート、ネットワーク容量、ローミング機能、およびサービス品質 (QoS) を提供するワイヤレスソリューションを提供するために、ワイヤレスネットワークを計画および設計するプロセスです。サイトサーベイレポートには、調査対象エリアのフロアプランと、ワイヤレスカバレッジエリアおよび信号強度が注記されます。物理ネットワーク図は、ケーブルやハードウェアなど、ネットワークを構成するコンポーネントの実際の物理的な配置を示すために使用されます。論理図は、ネットワークを介したデータの流れを示すために使用され、デバイスが相互に通信する方法を示すために使用されます。これらの論理図には通常、特定のネットワーク内のサブネット、ネットワークオブジェクトとデバイス、ルーティングプロトコルとドメイン、音声ゲートウェイ、トラフィックフロー、およびネットワークセグメントが含まれます
## In cybersecurity operations, which technology is primarily used for centralizing the collection, correlation, and analysis of security event logs from various sources?
### WAF（Web Application Firewall）は、Webアプリケーションへの通信を解析し、SQLインジェクションやクロスサイトスクリプティング（XSS）などの不正な攻撃を検知・遮断するセキュリティツールです。従来のファイアウォールでは防げないWebサイトの脆弱性を突く攻撃から、顧客情報やWebサイトを保護します。SIEM（Security Information and Event Management）は、企業内の多様な機器からログを収集、一元管理し、リアルタイムで相関分析を行って脅威を検出するセキュリティシステムです。
## 同僚がアンマネージド24ポートスイッチを設置しました。彼はこのデバイスを使用する際に発生する可能性のあるブロードキャストトラフィックの量を懸念しています。この24ポートスイッチ1台を使用した場合、いくつのブロードキャストドメインが作成されますか？
### アンマネージドスイッチは、ケーブルを挿すだけで動作する設定不要のスイッチングハブです。ブロードキャストドメインは1つでコリジョンドメインは24個
## 複数のスイッチが相互に通信できるように、アップリンクポートを設定しています。すべてのVLANは、指定されたサーバスイッチから通信する必要があります。VLAN 1が管理VLANでない場合、トランクポートには次のうちどれを設定する必要がありますか？
### トランクポートとは1つのポートに複数のVLANがある。アクセスポートとは1つのポートに1つのVLANである。アクセスポートにはスタックVLANとダイナミックVLANがある。トランクポートで必要なのはどのフレームがどのVLANのものか識別するためのタグ付け。その規格がIEEE 802.1Q

## どのタイプのクライアント・ツー・サイトVPN設定では、ローカルに専用のVPNソフトウェアをインストールすることなく、ユーザーがリモートで企業リソースにアクセスできますか？
### クライアントレス VPN 設定により、リモート ユーザーは専用の VPN クライアント ソフトウェアをインストールすることなく、Web ブラウザー経由で企業リソースに安全にアクセスできます。このタイプの VPN は、Secure Sockets Layer (SSL) などのテクノロジーを利用して、ユーザーのデバイスと企業ネットワーク間の暗号化された接続を確立します。
