- サンドボックスは例えば、怪しい添付ファイル、マルウェアっぽい実行ファイル、不審なURLなどを、普段使っているPCや社内ネットワークに影響が出ないように実行して挙動を確認します。ジャンプボックスは、社内の重要なサーバや管理ネットワークに直接アクセスさせず、いったん経由させるための中継サーバです。
- バッファとはデータを一時的に保存するメモリ領域でありキューが使われる。
- NATgatewayとはプライベートサブネット内のサーバーがインターネットからのアクセスを禁止してインターネットのサービスにアクセスできるためにある手法
- サブネットの種類としてインターネットゲートウェイを経由してインターネットと直接通信するパブリックサブネットとインターネットと直接通信せず、NATゲートウェイなどを経由して間接的に通信するプライベートサブネットがある。
- VPCとは、Virtual Private Cloudの略で、パブリッククラウド内に構築されるプライベートなクラウド環境です。
- パブリッククラウドとプライベートクラウドの最大の違いは、インフラの共有か専有かです。パブリッククラウドは他社とリソースを共有し、低コスト・短期間で導入可能です（AWS, Azure等）。一方、プライベートクラウドは自社専用の環境で、高セキュリティ・高カスタマイズ性ですが、コストと手間がかかります
- TCPのRSTフラグは接続を終了するために使用されます。このタイプの接続終了は、送信側が TCP 接続に何らかの問題が発生した、またはそもそも会話が存在すべきではなかったと判断した場合などに使用されます。FINフラグはコネクションの切断処理を行う。
- ミラーリングポート（ポートミラーリング）は、スイッチやルータの特定ポートを流れる通信データをコピーし、指定した別のポートへ転送する機能です。Wiresharkなどの解析ツールを接続することで、ネットワークのトラフィック監視、トラブルシューティング、パケットキャプチャに利用されます。
- ダイナミック ARP インスペクション (DAI) は、ネットワーク内のアドレス解決プロトコル (ARP) パケットを検証するセキュリティ機能です。DAI を使用すると、ネットワーク管理者は、無効な MAC アドレスと IP アドレスのバインディングを持つ ARP パケットを傍受、ログに記録、破棄できます
- 802.3系は有線LAN、802.11系はWi-Fi、802.1系はLAN制御系、VLAN、認証、STPなど
- NAC（Network Access Control）デバイスをネットワークに接続する際にセキュリティポリシー（セキュリティパッチ、OSなど）に準拠しているかどうか確かめ、準拠していない場合はアクセスを制御する手法。
- VLSMはVLSM（Variable Length Subnet Mask）は、同じ大きなネットワークの中で、場所ごとに違うサブネットサイズを使うことです。192.168.1.0/24 - 192.168.1.0/26    端末が多い部署, 192.168.1.64/28   小さい部署192.168.1.80/30   ルーター間接続といった具合。
- クラスレスプロトコルとは、ルーティング情報を交換するときに、IPアドレスだけでなくサブネットマスク／プレフィックス長も一緒に扱えるルーティングプロトコルのことです。クラスフルは機器がサブネットまで認識できないので固定長のサブネットマスクしか使われなかった。OSPF, EIGRP, RIPv2, BGP
- 輻輳congestionとは通信回線が混雑すること
- QoS（Quality of Service）でIPを使った通信サービスの品質を保証するための技術
- フルサービスリゾルバ、DNSキャッシュサーバが調べてでも答えを持って来てというのが再起問い合わせでもし知っていたらが非再帰問い合わせ（クライアントからDNSキャッシュサーバへ）や反復問い合わせ（キャッシュDNSサーバからDNSコンテンツサーバへ）という。と自分の持っている対応表が権威DNSサーバ、DNSコンテンツサーバ。自分の情報が書かれてるのをゾーンファイルという。これを設定しているのが人間でそれをされたサーバをプライマリDNSサーバといいそのサーバからゾーンファイルを教えてもらったのをセカンダリDNSサーバという。
- ジャンボフレームは意図的に大きくしていて（1500以上）、ジャイアンツフレームはEthernetではフレーム最大サイズが1518 bytesなのでそれを超えるもの
- ドロップとはスイッチのバッファがいっぱいで受信フレームを処理できない時におこる現象
- CRCは巡回冗長検査（Cyclic Redundancy Check）。通信データに誤りがないか確認する検出方式。
- SVI（Switch Virtual Interface）は論理的なネットワーク（VLAN）同士を合体させるときに、L3スイッチがそれぞれのVLANとやり取りするための接点のこと
- データセンターのパッチパネルには、ネットワーク接続を保護し、ケーブルインフラストラクチャへの不正アクセスや改ざんを防止するためのロック機構を装備できます。
- AUP（Acceptable Use Policy）許容使用ポリシー (AUP) は、ネットワーク、Web サイト、またはサービスの所有者、作成者、または管理者によって適用される一連のルールであり、ネットワーク、Web サイト、またはシステムの使用方法を制限し、使用方法に関するガイドラインを設定します。
- 多層防御（Security in depth）は、貴重なデータと情報を保護するために一連の防御メカニズムを階層化するサイバーセキュリティのアプローチです。
- ゼロトラスト（Zero Trust）とは、「何も信頼しない（Never Trust, Always Verify）」を前提に、すべてのアクセスを検証するセキュリティの考え方です。社内・社外の区別なく認証・認可を厳格化し、クラウドやリモートワーク環境での脅威を防ぐ、従来の「境界防御」に代わる次世代のセキュリティモデルです。
- 最小権限（least privilege）は、ユーザー、アカウント、およびコンピューティング プロセスのアクセス権を、日常的で正当な活動を実行するために絶対に必要なリソースのみに制限するという概念と実践です。
- ネットワークファイアウォールは、FILTEREDされたすべてのポートをブロックしています。
