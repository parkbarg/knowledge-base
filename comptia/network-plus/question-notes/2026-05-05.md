- on demand（オンデマンド）は「要求があれば（直ちに）」「利用者の要求に応じて」という意味の英語で、必要なものを必要な時に提供するサービス方式のことです。
- Metered services（メータード・サービス、従量制サービス）とは、IT、クラウドコンピューティング、および公共料金において、サービスの実際の使用量（消費量）に基づいて料金が発生する支払いモデルです。
- リソースプーリング（Resource Pooling）とは、クラウドや仮想化環境において、CPU、メモリ、ストレージなどのIT資源を論理的に1カ所にまとめ（プール化）、複数のユーザーや仮想マシンで共有・効率的に配分する仕組みです。
- Rapid elasticity（ラピッド・エラスティシティ、迅速な弾力性）とは、クラウドコンピューティングの主要な特徴の一つで、需要に応じてコンピューティングリソース（サーバー、ストレージ、ネットワークなど）を、自動かつ迅速に拡張（スケールアウト）または縮小（スケールイン）できる能力のことです。
- 軽量AP（Lightweight AP）は管理に中央コントローラを使用するため、ショッピングモールなどの大規模な展開に最適で、シームレスなローミングと集中制御を実現します。
- standalone APとAutonomous AP（自律型）は自律型で自律型APは中央コントローラなしで独立して動作するため、シームレスなローミングと集中管理にはあまり適していません。
- メッシュAPは無線で相互接続してネットワークを形成しますが、広いエリアに不可欠な集中管理機能を提供しない場合があります。
- キャプティブ ポータルは、完全なインターネットアクセスを提供する前に、ユーザーをログイン ページまたは利用規約の同意ページにリダイレクトします。
- 構成ドリフトとは、ネットワーク機器の構成が意図した状態から意図せず徐々にずれていく状態を指します。
- 企業データをすべてSaaSソリューションに移行すると、データとその保護に対する完全な制御が失われます。企業が機密データをクラウドベースのソリューションに移行する予定がある場合は、プライベートクラウドソリューションまたはPaaS/IaaSソリューションを検討すべきです。
- Omnidirectional Antenna（無指向性アンテナ）は全方向。Unidirectional Antenna（単一指向性アンテナ）は一方向に電波を飛ばしたい基本的なやつ。Parabolic Antennaは電波を一点に集中させる強い指向性アンテナである。マイクロ波通信、衛星通信、長距離ポイントツーポイント通信に使用される。Yagi Antennaは一方向で長距離でポイントツーポイントである。
- 変更管理プロセス：要求提起->評価・分析->承認->実装->レビュー。緊急変更では緊急承認を得る→すぐ変更する→あとで詳細に記録する
- ネットワークセキュリティリストは、特定のクラウド リソースとの間のトラフィックを詳細に制御し、管理者がセキュリティとトラフィック フローをきめ細かく管理できるようにします。パブリック クラウドおよびプライベート クラウドのピアリング ソリューションは、異なるクラウド 環境間でのデータ交換を可能にしますが、ネットワーク セキュリティ リストと同じレベルのトラフィック制御は提供しません。
- アップデート前にバックアップを行う
- BPDUとSTPはセット
- Granular Trap（きめ細やかなトラップ）とVerbose Trap（冗長なトラップ）は、SNMPによるネットワーク監視における通知情報の詳細度合いの違いです。Granularは特定のOID値のみを含む軽量・高速通知、Verboseは詳細なイベント情報を含む重量・詳細通知で、前者は帯域消費を抑え、後者は詳細な調査に向きます。
- DHCPサーバーが配るものはIPアドレス、サブネットマスク、デフォルトゲートウェイ、DNSサーバです。
- 境界点（Demarcation point）でMDFで終端する。
- ハニーポットは、情報システムの不正使用の試みを検出、回避、または何らかの方法で対抗するように設定されたコンピュータ セキュリティ メカニズムです。ハニーポットは、攻撃者を誘い込むための仮想トラップを作成するセキュリティ メカニズムです。意図的に侵害されたコンピュータ システムでは、攻撃者が脆弱性を悪用できるため、攻撃者の手法を研究し、セキュリティ ポリシーを改善できます
- 共通脆弱性識別子 (CVE) システムは、一般に知られている情報セキュリティの脆弱性と暴露に関する参照方法を提供します。CVE は Web サイトとデータベースであり、ネットワークにインストールまたは構成するものではありません。
- FHRP (First Hop Redundancy Protocol) は、LAN内の複数のルータやL3スイッチを論理的に1台の仮想ルータとして運用し、デフォルトゲートウェイを冗長化するプロトコル群の総称です。物理ルータ1台が故障しても、仮想IP/MACアドレスを引き継ぐことで、クライアント側の設定変更なしに自動で通信経路を切り替え、高いネットワーク可用性を確保します。

- QoSはIPサービスの優先度をつける。DSCP（Differentiated Services Code Point）は、IPヘッダ（ToSフィールド）の6ビットを使ってネットワークパケットを最大64段階で分類し、優先度（QoS）を制御する技術です。
- ポートセキュリティは、ネットワークスイッチの物理ポートごとに、通信を許可する端末のMACアドレスを制限し、不正な機器接続を防止するレイヤー2の機能です
- DHCPスヌーピングとは、スイッチングハブがDHCPサーバーとクライアント間の通信（パケット）を監視・のぞき見（Snooping）し、不正なDHCPサーバーやなりすまし通信を遮断するセキュリティ技術です。信頼できるポート（サーバ側）と信頼できないポート（端末側）を定義し、偽のIPアドレス配布や通信盗聴などの攻撃を防ぐ役割を果たします。
- ファイバーチャネル (FC) は、ストレージエリアネットワーク (SAN) での高速データ転送用に特別に設計されており、サーバーとストレージデバイスを接続するのに理想的な選択肢です
- DHCP Reservation（DHCP予約/IPアドレス予約）は、DHCPサーバー（ルーター等）が特定のMACアドレスを持つ端末に対し、常に同じIPアドレスを自動的に割り当てる機能です。
- DHCPリレー（DHCP Relay Agent）は、ルーターやL3スイッチを挟んで異なるサブネットに存在するDHCPクライアントとサーバー間で、DHCPのブロードキャスト通信をユニキャストに変換して中継する機能です。これにより、各セグメントにDHCPサーバーを配置せず、1台のサーバーで複数拠点のIP管理が可能になります
- RTP（Real-time Transport Protocol）は、インターネット上で音声や動画などのデータを、リアルタイムに配信するための通信プロトコルです。遅延が許されないIP電話（VoIP）やビデオ会議、ストリーミング配信で使われ、主にUDPを使用し、高速にパケットを届ける役割を果たします
- H.323は、IPネットワーク（LANやインターネット）上でリアルタイムの音声・映像・データを送受信するための国際標準プロトコル（通信規約）です。テレビ会議システムやIP電話（VoIP）で長年利用されてきましたが、現在はより軽量なSIPへの移行が進んでおり、主に旧式の機器やレガシーシステムとの相互接続用として使用されています。
- アドホックネットワークは簡易的なピアトゥーピア
- ネットワークにおけるVIP（Virtual IP Address：仮想IPアドレス）とは、特定の物理的な機器（NIC）に固定されない、論理的に構成されたIPアドレスのこと。負荷分散（ロードバランサー）や高可用性（HA/冗長化）を実現するため、複数のサーバーで共有される。1つのIP宛の通信を複数の実サーバーへ効率的に振り分ける際に不可欠な技術。
- ルートポイズニング（Route Poisoning）は、ディスタンスベクタ型ルーティングプロトコル（RIPなど）において、障害が発生した経路のメトリックを最大値（16）に設定し、「到達不能」として周囲に通知する仕組みです。これにより、誤った古い情報を近隣ルータが再利用するのを防ぎ、ルーティングループの発生を未然に回避します。
-  スプリットホライズン（Split Horizon）は、ディスタンスベクタ型ルーティングプロトコル（RIPなど）において、あるインターフェースから受信したルーティング情報を、同じインターフェースへ送り返さないというルールです。これにより、不正確な情報が伝播してルーティングループ（循環経路）が発生するのを防ぎます。
- ホールドダウンタイマー（Hold-down timer）はルーターが落ちた時更新を防ぎ、ルーティングテーブルの共有に重きをおく。
